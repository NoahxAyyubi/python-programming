# Assignment 5 - Modular Programming

This program prints a grade report for three sample students.

- `main.py` runs the program and uses `datetime` to show today's date.
- `grade_tools.py` finds averages and letter grades.
- `report_tools.py` puts the results into text.

Keep the three Python files together in the `assignment5` folder.
Open a terminal in that folder and run:

```sh
python3 main.py
```

From the course repository folder, you can also run:

```sh
python3 assignment5/main.py
```

No extra packages are needed.
